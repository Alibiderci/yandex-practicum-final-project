# Планировщик задач (Итоговый проект Яндекс.Практикум)

Это веб-приложение для управления задачами, разработанное в рамках итогового дипломного проекта курса "Go-разработчик".

Проект представляет собой бэкенд на Go, который предоставляет REST API для фронтенда. В качестве базы данных используется SQLite.

Подготовлен `Dockerfile` для сборки и запуска приложения в изолированном контейнере.

## Инструкция по запуску локально

### Требования
   Go версии 1.24 или выше.

### Установка переменных окружения
Для корректной работы приложения необходимо задать следующие переменные окружения. Их можно поместить в файл `.env` и запустить с помощью `source .env` или установить напрямую в системе.

# Порт, на котором будет работать веб-сервер
export TODO_PORT=7540

# Путь к файлу базы данных SQLite
export TODO_DBFILE="scheduler.db"

# Путь к директории с файлами фронтенда
export TODO_WEBDIR="web"

# Пароль для доступа к API. Если переменная пустая, аутентификация будет отключена.
export TODO_PASSWORD="12345"


### Запуск
Для запуска сервера выполните команду из корневой папки проекта:

go run main.go

После запуска приложение будет доступно в браузере по адресу: http://localhost:7540

## Инструкция по запуску тестов

Для запуска всех тестов выполните команду:

go test ./tests


### Настройка тестов для аутентификации
Если вы запускаете тесты с включенной аутентификацией (`TODO_PASSWORD` установлен), вам необходимо предварительно сгенерировать валидный JWT-токен и вставить его в файл `tests/settings.go`.

1.  Запустите сервер с установленным `TODO_PASSWORD`.
2.  Откройте `http://localhost:7540/login.html`, введите пароль и войдите.
3.  Откройте инструменты разработчика в браузере (F12), перейдите на вкладку "Application" (или "Приложение") -> "Cookies".
4.  Скопируйте значение cookie с именем `token`.
5.  Вставьте это значение в переменную `Token` в файле `tests/settings.go`:

    // tests/settings.go
    var Token = `вставьте_скопированный_токен_сюда`


## Инструкция по запуску через Docker

### Требования
Docker Desktop или Docker Engine.

### 1. Сборка Docker-образа
В корневой папке проекта выполните команду:

docker build -t task-manager .


### 2. Запуск контейнера
Выполните следующую команду, чтобы запустить контейнер. Она настроит порты, подключит локальный файл базы данных и передаст необходимые переменные окружения.


docker run -d \
  -p 7540:7540 \
  -v "$(pwd)/scheduler.db:/app/scheduler.db" \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE="/app/scheduler.db" \
  -e TODO_PASSWORD="12345" \
  --name task-manager-container \
  task-manager

После этого приложение также будет доступно по адресу http://localhost:7540.

### Управление контейнером
Остановить контейнер: `docker stop task-manager-container`
Запустить остановленный контейнер: `docker start task-manager-container`
Удалить контейнер: `docker rm task-manager-container`
